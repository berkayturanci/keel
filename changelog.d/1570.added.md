- **Opt-in COMMENT-consensus merge rule, and base facts for the jury** (#1570). With `knobs.team.jury.comment_consensus` on, a jury verdict whose consensus is `COMMENT` satisfies `jury-verdict` when its findings summary has no `critical`/`major` item, at least `min_approvals` (default 2) distinct review verdicts approve at the head, and none there fails to approve. `keel merge` then files the remaining minor findings as one follow-up issue before merging, records it in the run ledger as a new `jury_followup` record so a retry reuses it, and refuses the merge if the issue can't be filed. `REQUEST_CHANGES`, `ABSTAIN`, `NO_QUORUM` and any blocking finding still stop the merge. With `knobs.team.jury.base_facts` on, the rendered PR body gets a `## Base facts` section, and the jury reads it ahead of the diff as claims to verify against the head checkout. The s8 `jury` gate reads it from the pull request, and the s7 panel gets it through the new `keel jury-diff`.
