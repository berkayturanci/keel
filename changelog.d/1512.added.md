- **`keel stale-blockers` lists open PRs whose stated blocker has cleared** (#1512). Checks PR bodies that state `blocked by #N`, `depends on #N`, `waiting on #N`, `blocked until #N`, `dependency: #N` / `needs dependency: #N`, or `do not merge before #N|<tag>` against GitHub (`cleared` when merged/completed or tagged, `abandoned` when closed unmerged or not planned, `pending` while open, `unknown` when a lookup fails with exit 2), marks PRs with unread or foreign references in a blocker zone `incomplete: true` so `all_cleared` stays false, and wires the check into `/keel:stale-prs` and `/keel:morning`. See `docs/keel/cli.md` (`keel stale-blockers`) for the full phrase, tag, and zone grammar.
