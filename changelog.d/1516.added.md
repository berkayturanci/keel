- **Isolated review checkout for the `jury` gate and adapter reviewer guidance** (#1516). `swarm_runtime.review_checkout` and `jury.run_gate(..., head_sha=...)` allocate unique, invocation-owned detached checkouts under `.keel/worktrees/review-*` for the built-in `jury` gate (translating configuration-copy `OSError` failures into `ReviewCheckoutError`, copying `jury.toml`, `jury-policy.toml`, and `.jury/` entries only when untracked at the reviewed head and in the working-tree index, refusing on path collisions, and warning if worktree removal fails); the `ship` and `review-cycle` adapters recommend per-seat `.keel/worktrees/review-*` detached checkouts cleaned up via `keel worktree-remove` (with the `ship` adapter's `jury` panel, synchronous reviewer/gate, and detached collect blocks failing closed on checkout, configuration-copy, dispatch, or cleanup errors before evidence conversion).
- **Behaviour change — `keel ship` `jury` gate runs in a detached checkout** (#1516). When `keel ship` runs the `jury` gate, it executes `jury` in a fresh detached checkout of the reviewed commit (`--head-sha` or `HEAD`), copying `jury.toml`, `jury-policy.toml`, and `.jury/` entries from the repository root only when untracked at the checkout head and in the working-tree index (tracked configuration comes from the checkout itself, never from the working tree); uncommitted working-tree edits, tracked configuration introduced after `--head-sha`, and other untracked directories (e.g. `.keel/state`) are not visible to the panel.
- **Staged contamination warnings on `keel ship` and `keel wrap`** (#1516). `keel ship` and `keel wrap` check `git diff --cached --diff-filter=MD` (staged modified `M` and deleted `D` paths; newly added `A` files are excluded) against `--implementer-file` (with `keel ship` also falling back to `--declared-file` or the PR's ledger `declared.files`), `--since` (a committed-history baseline; **behaviour change**: `keel wrap --since` queries git history when `--implementer-file` is omitted, warning when `--since` is unresolvable or has no commits), or by default the branch's committed diff against `base_branch`, warning on stderr and in the JSON result when staged modified or deleted files fall outside the baseline.
