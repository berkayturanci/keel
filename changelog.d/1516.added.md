- **Reviewer seats run in separate checkouts and ship/wrap warn on staged contamination** (#1516). Reviewer seats (host agent, subagents, delegates, and the jury panel) are dispatched in isolated read-only checkouts of the PR head (`.keel/worktrees/review-*` created with `git worktree add --detach`) and cleaned up with `keel worktree-remove` so exploratory review tests or red-proof deletions never mutate the implementer's worktree. In addition, `keel ship` and `keel wrap` accept `--implementer-file` and `--since` to detect and warn (on stderr and in the structured JSON result) when staged modified or deleted files include paths not touched by the implementer run.
