- **Drift checks line survival instead of warning on every shared file** (#1511). `verify_merge` now verifies line survival across every overtaking pull request per shared file using multiset counting against each overtaking PR's landed version. For each added line, its count in the merge commit must be >= its count in the PR's landed version; for each deleted line, its count in the merge commit must be <= its count in the PR's landed version (catching re-added deletions). Whole-file deletions (`+++ /dev/null`) are verified not to reappear in the merge commit. Reports `clean (N shared files, 0 lost lines)` when all changes survive, and conservatively reports `drift` if added lines are missing, deleted lines are re-added, deleted files reappear, diffs are truncated or malformed, or file content at either commit is unreadable.
