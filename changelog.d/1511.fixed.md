- **Post-merge drift check verifies added-line survival against the merge commit's first parent before flagging shared files** (#1511). `keel verify-merge` (and `keel merge`'s post-merge check) now checks whether non-blank lines added by every overtaking PR and still present in the merge commit's first parent (`<merge_sha>~1`) appear in the merge commit's file content (URL-encoding file paths on the contents endpoint; standalone deletions are not verified), reporting `clean (N shared files, 0 lost lines)` when all survive and `drift` (with per-PR `lost_lines` attribution and per-file `unverifiable_prs` fallback for deleted, renamed, binary, or unreadable files) only when lines were lost or could not be verified.
