- **Post-merge drift check verifies added-line survival before flagging shared files** (#1511). `keel verify-merge` (and `keel merge`'s post-merge check) now checks whether non-blank lines added by an overtaking PR still appear in the merge commit's file content, reporting `clean (N shared files, 0 lost lines)` when all survive and `drift` (with `lost_lines` counts/samples or `unverifiable` fallback for deleted, renamed, binary, or unreadable files) only when lines were lost or could not be verified.
