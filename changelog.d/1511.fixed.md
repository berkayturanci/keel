- **Merge drift checks multiset line survival across overtaking PRs on shared files** (#1511). `verify_merge` now compares non-blank added and deleted line counts on shared files between each overtaking PR's landed `merge_commit` and the merge commit (`clean (N shared files, 0 lost lines)` when disjoint edits survive), while whole-file deletions and `rename from` paths are checked via `FILE_ABSENT`. Overlapping edits to the same lines, re-added deleted lines, reappearing deleted files, and unreadable or unverifiable inputs (truncated/huge diffs, missing content, or shared mode/binary/hunkless changes) conservatively report `drift` (`the shape of a silent revert` vs `could not verify line survival (fail-closed)`). **Breaking (JSON report schema `keel.merge-verify.v2`):** `overtaken` changes from `{path: int}` to `{path: [int, ...]}` (`{}` when `clean`), and reports add `shared_files` (`list[str]`) and `drift_details` (`dict[str, list[str]]`).
